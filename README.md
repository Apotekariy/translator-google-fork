 Translator App

Android-приложение для перевода текста с использованием Google Translate API.

## Стек

Технологии и паттерны, использованные в проекте:

- **Kotlin + Jetpack Compose (Material 3)**: Современный декларативный UI.
- **Clean Architecture**: Разделение кода на слои (Data → Domain → Presentation).
- **Hilt**: Внедрение зависимостей.
- **Retrofit + Kotlin Serialization**: Работа с сетью и парсинг JSON.
- **Room**: Локальное кеширование переводов.
- **Coroutines + Flow**: Асинхронное программирование и обработка потоков данных.

## Функции

### Переводчик

- **Перевод текста**: Поддержка 5 языков (EN, RU, ES, FR, DE).
- **Смена направления перевода**: Переключатель между исходным и целевым языком.
- **Progress bar**: Индикация процесса загрузки перевода.
- **Кеширование результатов**: Сохранение переводов для быстрого доступа офлайн.
- **Обработка ошибок**: Информативные сообщения об ошибках сети или API.

### История

- **Список всех переводов**: Удобный просмотр всех выполненных переводов.
- **4 варианта сортировки**:
  - По дате (новые сначала)
  - По дате (старые сначала)
  - По исходному тексту (А-Я)
  - По переведенному тексту (А-Я)
- **Swipe to delete**: Удаление отдельных переводов свайпом влево.
- **Очистка всей истории**: Функция для удаления всех переводов одним нажатием.
- **Детали перевода**: Переход на отдельный экран для просмотра полной информации о переводе.
